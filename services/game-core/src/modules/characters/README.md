# Characters module

Sở hữu: `characters`, `family_trees`, `wills`, `trust_funds`.

Trách nhiệm:

- Hồ sơ nhân vật, tuổi, sức khỏe, vị trí, hôn nhân.
- Cây gia tộc, thừa kế, quỹ tín thác.
- Tổng hợp tài sản ròng cho hồ sơ (đọc qua module tài chính, không tự ghi bảng khác).

Không thuộc module này:

- Tính lãi vay/credit score (banking + domain).
- Giao dịch cổ phiếu (stock-market).
- Di chuyển realtime (realtime service chỉ phát; core xác thực khi cần).
