# real-estate

Sở hữu: `map_nodes`, `roads`, `properties`, `buildings`, `leases`, `auctions`.

- Mua/bán/cho thuê/xây dựng bất động sản.
- Giá đất theo zone, mặt tiền, quy hoạch.
- Thế chấp tài sản (phối hợp `banking`).
- Đấu giá tài sản phát mại (phối hợp `banking`).

Event: `property.sold.v1`, `lease.signed.v1`, `building.upgraded.v1`, `auction.closed.v1`.
