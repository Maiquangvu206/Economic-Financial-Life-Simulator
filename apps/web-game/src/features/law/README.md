# law

Pháp lý, tòa án, hôn nhân, thừa kế.

- Phiên tòa realtime trong `courtroom_session:*`.
- AI Thẩm phán chỉ trả về proposal; core kiểm tra bằng chứng và luật trước khi áp dụng.
- Bằng chứng, hợp đồng hôn nhân, di chúc, trust fund.
- Audit thuế và rủi ro thanh tra.

API: `/api/v1/law/*`, `/api/v1/evidence/*`.
Realtime: `courtroom_session:*`, `court:verdict`.
