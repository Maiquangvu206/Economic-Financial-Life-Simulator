# real-estate

Sổ bất động sản, cho thuê, xây dựng, thế chấp và đấu giá.

- Bản đồ và ô đất lấy từ `map_nodes`/`roads`, render bởi Phaser.
- Mutation mua/bán/cho thuê/đấu giá phải qua API server-authoritative.
- Giá đất, hệ số mặt tiền và quy hoạch do admin panel cấu hình.

API: `/api/v1/real-estate/*`.
Realtime: `city_map_room:*`.
