# finance

Tài chính cá nhân và ngân hàng.

- Bảng cân đối tài sản/nợ, dòng tiền theo tick.
- Credit score, hạn mức vay, lãi suất.
- Gửi tiết kiệm, vay thế chấp, cầm cố, P2P lending.
- Cảnh báo grace period và phát mại.

API: `/api/v1/banking/*`, `/api/v1/characters/me/finance`.
Realtime: `notification`, `macro:snapshot`.
