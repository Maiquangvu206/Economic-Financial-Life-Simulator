# underworld

Chợ đen, thám tử tư, tống tiền và trả thù ngầm.

- Hợp đồng điều tra, thiết bị, bằng chứng.
- Blackmail contract, sting operation, heist, sabotage.
- Heat Level và Đại án Công an toàn server.
- Mọi hành động phi pháp đều qua server; client chỉ hiển thị.

API: `/api/v1/underworld/*`.
Realtime: `notification`, `admin_room` (cảnh báo sweep).
