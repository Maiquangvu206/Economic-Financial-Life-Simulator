# offline-recap

Tổng hợp thu nhập/chi phí và biến động thị trường trong thời gian offline.

- Dữ liệu do worker tổng hợp theo tick, không tính lại ở client.
- Hiển thị sau khi đăng nhập lại.
- Có thể chia sẻ dưới dạng summary, không lộ dữ liệu người chơi khác.

API: `/api/v1/characters/me/offline-recap`.
